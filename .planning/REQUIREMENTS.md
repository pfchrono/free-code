# Requirements

## Scope

This v1 project produces a clear comparison of prompt autocomplete behavior across Hermes, NexAgent, and free-code, then turns that comparison into a prioritized parity recommendation for free-code.

## v1 Requirements

### External Benchmarking

- **EXT-01**: The project must document Hermes prompt autocomplete behavior, including how command discovery, accept, navigation, and dismiss flows work from the user perspective.
- **EXT-02**: The project must document NexAgent's exposed command/session interaction surface and clearly state whether it is a meaningful autocomplete benchmark.

### free-code Behavior Audit

- **AUD-01**: The project must summarize current free-code autocomplete behavior across slash commands and other suggestion families, with source-traceable references to the current implementation.

### Gap Analysis

- **GAP-01**: The project must identify current free-code strengths relative to Hermes so the recommendation preserves differentiators instead of only listing shortcomings.
- **GAP-02**: The project must identify concrete UX and architecture gaps between free-code and Hermes-quality command completion, including discovery, argument completion, and suggestion-system structure.

### Recommendation Synthesis

- **REC-01**: The project must recommend a prioritized set of parity improvements for free-code, ordered by impact and explained with rationale.
- **REC-02**: The project must state a bottom-line recommendation that distinguishes what free-code should keep, what it should generalize, and what new UX surface it should add.
